04 AI engineering

Context, constraints and human judgement.

Copilot started as a way for me to write code faster. I now see it increasingly as a platform for building AI-assisted engineering workflows designed around context, constraints and human judgement.

  1. 01 Prompt Intent What do I want done right now? Use when the guidance is one-off and task-specific.
  2. 02 Instructions Constraints What rules should consistently apply? Use when it should apply repeatedly without being restated.
  3. 03 Skill Expertise How should this kind of work be done? Use when it represents reusable specialist expertise.
  4. 04 Agent Responsibility Who owns this workflow or role? Use when a worker owns a role or workflow.
  5. 05 Hook Automation What should happen automatically at a defined moment? Use when something should happen automatically at an event or boundary.
  6. 06 MCP External capability What systems, tools, or data does the workflow need access to? Use when the workflow needs access to an external system.

Use the smallest mechanism that solves the problem. The goal is not to use more features — it is to design better boundaries.
